# CustomerIQ Marketing Case Study Template

Only verified external evidence should be added to this framework.

| Field | Description |
| --- | --- |
| Company | Company or organization studied |
| Industry | Industry segment |
| Problem | Business or customer retention problem |
| Customer Situation | Customer context |
| Intervention | Intervention implemented |
| Strategy | Marketing strategy used |
| Target Segment | Segment targeted by the intervention |
| Channel | Channel used |
| Outcome | Observed measurable outcome |
| Lesson | Lesson for CustomerIQ rules |
| Relevant CustomerIQ Signal | Signal the case study is associated with |
| Applicability | When and where the case applies |
| Evidence Quality | Quality of the external evidence |
| Source | Source citation |
| Limitations | Known limits of the evidence |
